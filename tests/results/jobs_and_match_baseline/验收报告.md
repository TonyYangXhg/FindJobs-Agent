## 5. API 契约速查

### GET `/api/jobs`

- 默认：`page`（从 1）、`page_size`（默认 50，上限 100）
- 响应：`jobs`、`total`、`page`、`page_size`、`data_source`
- 列表字段：`id/title/company/location/required_skills/apply_url/...` + `description_summary`
- 兜底：`?all=1` 返回较全字段（含完整 description）

### POST `/api/jobs/match`

- 请求体：`resume_id`（必填）、`top_k`（默认 20，上限 100）
- 响应：`matches`（已裁剪）、`resume_id`、`top_k`、`total_matched`、`candidate_total`
